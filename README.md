# Maison Braise

A modern restaurant website designed to present the restaurant, showcase its atmosphere, and provide visitors with an easy way to explore its services.

## Overview

Maison Braise is a responsive restaurant website built with HTML, CSS, and JavaScript. The project focuses on a clear layout, an attractive visual identity, and a smooth browsing experience.

## Features

- Responsive website layout
- Restaurant presentation
- Navigation menu
- Reservation interface
- Bootstrap Icons
- Interactive elements with JavaScript

## Technologies

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Bootstrap Icons

## Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

For the best development experience, you can use the Live Server extension in Visual Studio Code.
